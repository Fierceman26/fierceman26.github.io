220 nm SOI，全刻蚀条形波导，氧化硅全包覆，无硅衬底。
波导宽 500 nm，在两侧做 `δ = 20 nm` 对称矩形侧壁齿：宽段 540 nm、窄段 460 nm，占空比 50%，周期 `Λ = 317.89 nm`，`N = 20` 个周期（光栅长 `6.3578 µm`），两端各接 `2 µm` 长的 500 nm 直引线。

在 Ansys Lumerical MODE 里用 3D EME 算这根光栅在 1552 nm 处的 TE0 反射率 `R_TE0`，按直觉加模数做收敛检查，结果却越算越不对劲：

- `M = 40`：`R = 0.08166`
- `M = 80`：`R = 0.08168`（看起来已经稳到 `2 × 10⁻⁵`）
- `M = 121`：`R = 0.07755`
- `M = 160`：`R = 0.06264`
- `M = 240`：`R = 0.08492`
- `M = 320`：`R = 0.08684`
- `M = 400`：`R = 0.09184`
- 窗口从 4 µm 扩到 5 µm（同样 `M = 320`）：`R` 又掉回 `0.07589`（`ΔR = −0.01095`）

更迷惑人的是，在整个剧烈跳变过程中，功率残差 `1 − R_TE0 − T_TE0` 始终纹丝不动地钉在 `0.0014` 左右。

**问题不在模式数不够，也不在 4 µm 窗口太小。**
真正的原因是：**Metal（PEC）盒里的介质加载波导在麦克斯韦方程中固有存在成对的复模（`n_eff = ±a + i b`），它们在 EME 多周期级联中引发了上百倍的数值爆炸；而 `energy conservation = "conserve energy"` 把爆炸后的散射矩阵强行投影回幺正矩阵，把发散伪装成了“模式未收敛”。**

| 器件 / 批次 | 状态 | 核心结论或边界 |
| --- | --- | --- |
| 定向耦合器 / Y 分支 / 微环谐振器 | 已完成 | 各自结果与 3D FDTD / 耦合批次已归档 |
| 布拉格光栅 Batch 1（均匀截面 FDE） | 已完成验收 | 500 nm 基准与 `δ = 20/40/60/80 nm` 宽窄截面 `n_eff`、`n_g` 及周期初估 `Λ_est2` |
| 布拉格光栅 Batch 2（20 周期 3D EME + 收敛） | **已完成验收** | 根因已定位；安全模基与 PML 交叉验证 16/16 单变量收敛全部通过（`10⁻⁴–10⁻³` 级） |

## 二、关掉 `conserve energy`，爆炸立刻现形

为了不改动任何已签字工程，我在 `neff_evidence_m400_v1.lms`（4 µm 窗口，四分之一对称 Metal：`y min = Anti-Symmetric`, `z min = Symmetric`, `y max = z max = Metal`，芯区 `5 nm` 加密，外区 `20 nm`）的隔离副本上，先用 `override max modes` 拉出一条密集的截断曲线。

在原本开启 `conserve energy` 时，就已经能看到极不正常的尖峰与深谷：
`m = 23 → 70` 还平稳地停在 `0.0808 → 0.0821`，到了 **`m = 146` 突然腰斩到 `R = 0.03988`**，`m = 147` 单模跳回 `0.06211`，`m = 190` 又窜升至 `0.09112`，同时 `1 − R − T` 依然像假表盘一样死死卡在 `0.0014`。

随后保持几何、网格、边界完全不变，**只把 `energy conservation` 改成 `"none"`**，逐模扫描 `m = 1..160`，真相一秒暴露：

| 截断模数 `m` | `R_TE0`（`ec = none`） | `T_TE0`（`ec = none`） | `R + T` | 该模在 `cell_1 / cell_2 / cell_3` 中的特征 |
| ---: | ---: | ---: | ---: | --- |
| 1 | 0.07704 | 0.95641 | 1.03345 | 单模重叠小于 1，40 界面累积 `+3.3%` 非无源 |
| 23 | 0.08161 | 0.92744 | 1.00906 | 23 个纯传播模全部闭合，收敛趋近 1 |
| 40 | 0.08020 | 0.92300 | 1.00320 | 非无源误差已收敛至 `+0.32%` |
| **43** | **0.08017** | **0.92164** | **1.00181** | **纯倏逝模，已干净收敛到 `0.18%` 无源** |
| 44 | 0.02432 | 1.09182 | 1.11614 | 引入复模对前半 `n_eff = −0.0014 + 1.447j` |
| **45** | **12.37750** | **1.55393** | **13.93143** | **引入复模对后半 `+0.0014 + 1.447j`，`R` 单步暴涨 154 倍** |
| 160 | 15.55033 | 6.19751 | 21.74784 | 底层散射矩阵彻底炸到 `2175%` |

`m = 43` 时系统还健康得近乎完美（`R = 0.08017, T = 0.92164, R+T = 1.00181`）；仅仅多加到 **`m = 45`**，反射率就一步从 `0.080` 炸到 **`12.38`**。

换成 `"make passive"` 也救不了：它只是把奇异值硬截断到 `≤ 1`，`m = 146` 照样砸到 `R = 0.03377`，还凭空制造出约 15% 的假损耗（`T ≈ 0.77`）。而 `"conserve energy"` 则把 `R = 15.55, T = 6.20` 这坨已经发散的矩阵强行投影回幺正球面，每多进一对高阶复模，投影落点就随机飘一次——这就是之前 `M = 120 → 160 → 240 → 320 → 400` 永远停不下来的全部秘密。

## 三、唯一根因：Metal 盒复模四元组与单界面奇异值爆炸

为什么 `m = 44/45` 威力这么大？检查各单元的 `neff` 和功率正交矩阵 `Pmatrix`，结构一眼就能看穿：

1. **介质加载金属波导的真实复模**：无耗金属（PEC）盒里放入高折射率硅芯后，麦克斯韦方程本身就存在 Clarricoats–Taylor 复模四元组 `n_eff = ±a + i b`（例如 `cell_1` 中 mode 44/45 为 `∓0.00142 + 1.44675j`；到 `M = 400` 时多达 88–100 个复模）。
2. **强烈的非功率正交性**：复模对的自功率是纯虚数（`P[i, i] = ±1j`），而两个共轭同伴之间的**交叉功率是巨大的实数**：
   - mode 44/45：`P[44, 45]` 在 `cell_1 / cell_2 / cell_3` 中分别为 `16.12`、`27.64`、`9.03`；
   - 到 `M = 320–400` 时，mode 287/288 的 `|P[287, 288]|` 甚至飙到 **`87.13`**。
   - 这也顺带解释了历史记录里“为什么请求 120 个模却返回 121 个，截掉第 121 个模 `R` 就跳 `0.00134`”——mode 120/121 正是一对 `∓0.00494 + 3.05976j` 复模，硬截到 120 把复模对劈开了。
3. **单界面实测给出精确放大倍数**：单独建一个极短引线（10 nm）的 `540 nm → 460 nm` 单台阶模型，读出内部散射矩阵 `S_int` 的最大奇异值：
   - `m = 23`（纯传播模）：`sv_max(S_int) = 1.004`，`max|S_ij| = 0.9997`；
   - `m = 40..44`（含较弱复模对 #31/#32，`P_off = 2.91`）：`sv_max = 3.015`，`max|S_ij| = 2.154` 落在 `(31, 32)` 复模交叉项；
   - **`m = 45`（加入复模对 #44/#45）**：**`sv_max(S_int)` 一步飙至 `14.56`**，最大元素 `|S(45, 44)| = 14.53` 精准落在复模对交叉透射项上。
   - 算一笔账：mode 45 的 `Im(n_eff) = 1.447`，走过半个周期 `Λ/2 = 158.945 nm` 的倏逝衰减是 `exp(−2π × 1.447 × 158.945 / 1552) = 0.394`。**单半周期净放大系数高达 `14.53 × 0.394 = 5.72 ≫ 1`。**
4. **周期级联引爆与全部对照排除**：
   - `N = 1` 周期尚看不出异常（`R = 0.00030`），`N = 2` 开始偏移（`0.00099 → 0.00091`），到 **`N = 5` 周期** `m = 45` 即原地爆炸 **2,280 倍**（`0.00556 → 12.802`）。
   - **排除周期组（`periodic groups`）算法 Bug**：把 `N = 5` 改成不启用周期复用、显式展开的 12 个独立 cell group，在 `m = 23..65` 上与周期组结果**逐位完全一致**（同样在 `m = 45` 炸到 `9.94505`）。
   - **排除非均匀加密网格与 `conformal` 网格**：均匀 20 nm 网格、均匀 10 nm 网格（无 `mesh_override`）以及 `staircase` 网格在 Metal 边界下全部照样出现 `10–12` 个复模（`max|P_off| = 14.6–33.2`）并在 `ec = none` 下照样爆炸（`R = 5.40–6.07`）。

## 四、窗口与模数彻底解耦：4 µm 和 5 µm 本来就重合

此前团队一度怀疑 4 µm 窗口不够大，因为 `N = 320` 时 4 µm 给出 `R = 0.08684`，5 µm 给出 `R = 0.07589`（差 `−0.01095`），才计划用面积比 `320 × (5/4)² = 500` 去解耦。

把 `neff_evidence_m320_w5um_v1.lms` 隔离副本也做一遍完整截断扫描，结果一清二楚：

| 物理阶段 | 4 µm 窗口 | 5 µm 窗口 | 差值 `|ΔR|` |
| --- | --- | --- | ---: |
| 全部传播模闭合（零复模） | `m = 23`：`R = 0.080819` | `m = 36`：`R = 0.080818` | **`1.0 × 10⁻⁶`** |
| 失稳前平台 | `m = 70`：`R = 0.082055` | `m = 100`：`R = 0.082271` | **`2.2 × 10⁻⁴`** |
| 复模失稳深谷（按面积比 `1.56×` 平移） | `m = 146`：`R = 0.039882` | `m = 240`（`146×1.56=228`）：`R = 0.057297` | 同源失稳 |
| 历史签字点 `N = 320` | `0.086841`（谷后大幅反弹） | `0.075890`（刚出 240 深谷） | `0.01095`（假偏移） |

**在复模失稳进来之前，4 µm 和 5 µm 在传播模闭合点重合到小数点后第六位（`1 × 10⁻⁶`）。**
所谓 `−0.011` 的窗口差异，不过是两个窗口恰好落在复模失稳深谷的不同相位上。即便当初把 `N = 500` 跑完，也只会顺着失稳反弹继续漂移，绝不可能收敛。

## 五、收敛解法与 Batch 2 验收数据

找到唯一根因后，正确的做法立刻清晰：

1. **从源头消掉负实部复模**：把外边界从 `Metal` 换回 **四分之一对称 12 层 PML**（`qsym_pml`），`Re(n_eff) < 0` 的复模数立刻归零（`negRe = 0`）。即使在 **`energy conservation = "none"`** 下，`m = 1 → 60` 也平滑收敛至无源值（`R = 0.08234, T = 0.91534, R+T = 0.9977`），与 `conserve energy`（`R = 0.08216, T = 0.91447`）仅差 `0.00018`。
2. **安全模基全波段扫描 + PML 交叉验证**：全波段逐点重算色散（1500–1600 nm 粗扫 51 点 + 0.2 nm 细扫 41 点 + 0.1 nm 峰检 13 点 + 等长 500 nm 直波导基线 12 点）采用严格限定在复模爆炸阈值之下的 `qsym_metal (M = 36)`，速度比 PML 快近 8 倍；并在 `1530 / 1550 / 1552 / 1570 nm` 四个代表波长上，用 `M = 40`、`2.5 nm` 局部网格、`5 µm` 面积匹配窗口以及 `qsym_pml (M = 60)` 完成完整单变量收敛矩阵。

核心结果如下：

- **直波导基线（等长 `10.3578 µm`）**：全波段 `max(R_TE0) = 2.424 × 10⁻³⁰`，`T_TE0 = 1.0000000000`。
- **20 周期光栅光谱（无 `R + T > 1` 异常，Palik 虚部全波段为 0）**：
  - 粗扫峰值：`1552.00 nm`，`R_TE0 = 0.081494`，`T_TE0 = 0.917050`
  - 0.2 nm 细扫与 0.1 nm 峰检一致锁定在 **`1551.80 nm`**，**`R_TE0 = 0.081496`**，**`T_TE0 = 0.917040`**，`1 − R − T = +0.001464`（`Δλ_peak = 0.00 nm`，`ΔR_peak = 0.000000`）。
- **四代表点 × 四项单变量收敛 = 16/16 全部 PASS**（Batch 2 阈值 `|ΔR|, |ΔT| < 0.01`）：

| 检查维度 | 1530 nm (`ΔR / ΔT`) | 1550 nm (`ΔR / ΔT`) | 1552 nm (`ΔR / ΔT`) | 1570 nm (`ΔR / ΔT`) |
| --- | --- | --- | --- | --- |
| 模式 `M=36 → 40` | `+0.00009 / -0.00009` | `+0.00015 / -0.00015` | `+0.00016 / -0.00016` | `+0.00008 / -0.00008` |
| 网格 `5 → 2.5 nm` | `-0.00016 / +0.00016` | `-0.00022 / +0.00022` | `-0.00022 / +0.00022` | `-0.00009 / +0.00009` |
| 窗口 `4 → 5 µm` | `+0.00016 / +0.00056` | `+0.00032 / -0.00018` | `+0.00030 / -0.00036` | `+0.00012 / -0.00076` |
| 边界 `Metal M=36 → PML M=60` | `+0.00033 / -0.00130` | `+0.00066 / -0.00251` | `+0.00067 / -0.00258` | `+0.00049 / -0.00269` |

在 `1552 nm` 的纯 `qsym_pml (M = 60)` 下，单变量变参同样达到 `10⁻⁴` 级：`M = 40 → 60` 时 `|ΔR| = 8 × 10⁻⁵`，`5 → 2.5 nm` 网格时 `|ΔR| = 2.2 × 10⁻⁴`，`4 → 5 µm` 窗口时 `|ΔR| = 1.1 × 10⁻⁴`。

## 六、别急着庆祝：独立 3D FDTD 交叉核对带来的清醒提醒

在完成 EME 收敛之后，又用 **3D FDTD** 在完全相同的 3D 几何与材料上跑了一遍独立交叉核对（`qsym PML`，核实过矩形尺寸、端口 `n_eff = 2.44268` 与 Palik 拟合折射率均与 MODE 一致）。结果非常值得写进笔记：

| 求解器与配置 | 周期 `N` | 峰值 / 参考 λ | `R_TE0` | `T_TE0` | `1 − R − T` |
| --- | ---: | ---: | ---: | ---: | ---: |
| MODE 3D EME（`qsym_pml M=60`, `5 nm`） | 20 | 1552.00 nm | 0.08216 | 0.91447 | +0.00337 |
| MODE 3D EME（`qsym_metal M=36`, `5 nm`） | 20 | 1551.80 nm | 0.08150 | 0.91704 | +0.00146 |
| **3D FDTD（`dx=13.25 nm, dy=dz=10 nm`, Palik）** | **20** | **1552.39 nm** | **0.13275** | **0.86583** | **+0.00143** |
| MODE 3D EME（`qsym_pml M=60`, `5 nm`） | 5 | 1552.00 nm | 0.00579 | 0.99173 | +0.00248 |
| **3D FDTD（`dx=7.95 nm, dy=dz=5 nm`, 精确常折射率）** | **5** | **1551.34 nm** | **0.00982** | **0.98798** | **+0.00221** |
| **3D FDTD（`dx=3.97 nm, dy=dz=5 nm`, 精确常折射率）** | **5** | **1551.34 nm** | **0.00954** | **0.98824** | **+0.00222** |

看得出两个非常扎实的结论：

1. **峰位、带宽与残差高度一致**：EME 峰位 `1551.80 nm`，3D FDTD 峰位 `1552.39 nm`，第一零点间距均贴合 `N = 20` 的物理长度，`1 − R − T` 同在 `0.0014–0.0034` 量级。
2. **反射幅值存在约 22% 的耦合强度模型差**：`N = 5` 时 3D FDTD 随 `dx = 7.95 → 3.97 nm` 已收紧在 `R = 0.00954`（对应 `N = 20` 约 `0.133–0.139`），高于 EME 收敛平台的 `0.00579`（对应 `N = 20` 的 `0.082`）。这是因为在 `Δε ≈ 10` 的硅/氧化硅 90° 锐角侧壁台阶上，真实电磁场存在 Meixner 介质楔角点奇异分量（空间尺度远小于 `40 nm` 齿宽），需要极高横向波数（`Im(n_eff) ≫ 10`）的倏逝模才能完整展开；而 EME 有限模基截断了这部分角点近场，且 Metal 边界早在 `m = 45` 就撞上复模失稳墙，不可能靠堆模数去追。

## 七、三条能直接带走的工程教训

1. **EME 里绝不要只盯着 `conserve energy` 下的 `1 − R − T` 判断收敛**：遇到高模数震荡，第一件事就是切回 `energy conservation = "none"` 看裸散射矩阵有没有在某个具体模式编号处突然爆炸，并同时检查 `Pmatrix` 的非对角最大值。
2. **Metal 边界不是“把模式数加到无穷大就一定更准”**：介质加载 Metal 盒里的 Clarricoats–Taylor 复模对在周期级联中会失稳；做硅光 EME 周期器件，要么用 **四分之一对称 PML** 消除负实部复模，要么把 Metal 模数严格锁在首个高 `P_off` 复模对之前。
3. **EME 与 3D FDTD 分工要清晰**：Batch 2 的有限光栅 EME 数值稳定性与收敛闭环现已全部打通；进入下一阶段（Batch 3 周期长度扫描、切趾/相移设计与流片级 `κ` 标定）时，最稳妥的组合是用 **细网格 3D FDTD（单周期能带或短周期基准）标定绝对 `κ`**，再用**安全模基 / PML 的 EME** 高效跑长器件与变参扫描。
