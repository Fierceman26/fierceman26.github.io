这是《Build a Large Language Model (From Scratch)》第 2 章的学习笔记。
神经网络只认数字，所以文本进入模型之前要走四步：

```text
文本 → ① 分词 → ② token ID → ③ 滑动窗口切出训练对 → ④ Embedding 向量（加位置）
```

## 分词与词表

先把句子切成 token，再给每个不同的 token 编一个整数 ID，就得到词表：

```python
tokens = ['Hello', ',', 'world', '.', 'This', 'is', 'a', 'test', '.']
vocab  = {'!': 0, ',': 1, '.': 2, 'Hello': 3, 'This': 4, 'a': 5, 'again': 6, 'is': 7, 'test': 8, 'world': 9}
```

词表是双向的：可以编码成 ID，也能解码还原。问题是，遇到词表里没有的词（比如 `Goodbye`）就会报错。

## BPE：GPT 真正使用的分词器

BPE（字节对编码）的做法是：常见词整个保留，生僻词拆成更小的片段。GPT-2 的词表大小是 50257。实际切分结果：

| 输入 | 切分结果 |
| --- | --- |
| `Hello, world.` | `Hello` `,` ` world` `.`，共 4 个。空格跟在词前面 |
| `unbelievableness` | `un` `bel` `iev` `abl` `eness` |
| `DesignCon PAM4 eye diagram` | `Design` `Con` ` P` `AM` `4` ` eye` ` diagram` |
| `你好，世界` | 11 个 token，被拆成字节碎片 |

关于“BPE 为什么不会遇到不认识的词”，有两点需要说清：

* BPE 的最底层单位是**字节**，任何文字最差也能拆成字节，所以不存在不认识的输入。中文被拆成字节碎片就是这个原因。
* 拆分**不是语言学上的词根拆解**。BPE 按“哪些字符片段在语料里经常一起出现”来合并，和语言学无关。`unbelievableness` 拆出的 `bel`、`iev` 并不是真正的词根。

两个实际影响：

* 专业术语会被拆得很碎。`PAM4` 被拆成 3 个 token，模型要靠上下文拼回它的含义。
* 英文词表对中文不友好。5 个汉字要用 11 个 token，所以中文场景应优先选择词表里包含中文的模型。

## 滑动窗口：自动造出训练数据

取一段文本，目标 y 就是输入 x 错开一位：

```text
x: The   cat   sat   on
y: cat   sat   on    the
```

一个窗口里**同时有 4 个训练样本**：

```text
看到 "The"            → 应预测 " cat"
看到 "The cat"        → 应预测 " sat"
看到 "The cat sat"    → 应预测 " on"
看到 "The cat sat on" → 应预测 " the"
```

这里有一个常见误解：以为窗口每次只错开一位、语料源源不断，准确性就会大大提升。准确性真正来自数据量大且多样。步长为 1 的窗口彼此大量重叠，信息高度重复。书里默认让步长等于窗口长度，以减少重叠，避免过拟合。

## 自监督与自回归：两个容易混淆的概念

| 概念 | 含义 | 发生在 |
| --- | --- | --- |
| 自监督 | 标签来自数据本身，不需要人工标注。“下一个词”就是现成的标准答案 | 训练 |
| 自回归生成 | 模型把自己刚预测的词拼回输入，再预测下一个 | 推理（使用） |

“预测出的词再作为新输入”描述的是自回归生成，ChatGPT 回答问题时文字一个个往外蹦就是这个过程。自监督说的是标签不用人工打。

训练时输入用的是**真实文本**，不是模型自己的预测。模型预测错了，错词也不会被喂给下一步。训练信号来自“预测的词和真实的词差多远”。

## Embedding：ID 变向量

整数 ID 本身没有意义，所以模型用一张**可学习的表**，把每个 ID 映射成一个向量。下面的例子每个 token 是 8 维，GPT-2 small 是 768 维：

```python
tok_emb = torch.nn.Embedding(50257, 8)   # 词表大小 × 向量维度
pos_emb = torch.nn.Embedding(4, 8)       # 上下文长度 × 向量维度
final = tok_emb(ids) + pos_emb(torch.arange(4))   # 形状 [4, 8]
```

* 这张表一开始是随机数，训练中和普通参数一样被梯度更新。训练完成后，意思相近的词，向量也会靠近。
* 注意力机制本身不知道词的先后顺序，所以再给每个位置加一个位置向量。最终输入是 token 向量加位置向量。

## 小结

* 文本进入模型前要经过：分词、词表、滑动窗口、Embedding。
* BPE 的最底层是字节，所以不会遇到不认识的输入，但它的拆分按统计，不按词根。
* 滑动窗口让文本自己提供标签，这就是自监督。自回归是推理时的生成方式，两者不是一回事。
