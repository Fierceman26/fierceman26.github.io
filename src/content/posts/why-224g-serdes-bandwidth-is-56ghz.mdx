做高频微波电路出身的工程师，在第一次接触 224 Gbps PAM4 这类超高速 SerDes（串行器/解串器）系统时，几乎都会经历一次剧烈的思维碰撞，甚至会陷入一连串看似无解的逻辑闭环：

- 疑惑一（采样率翻倍错觉）：224 Gbps 就是每秒传 224 G 个 bit。就算用了 PAM4（1 个符号代表 2 个 bit），每秒也要跳变 112 G 次（112 GBaud）。按照奈奎斯特采样定理，每个波形至少采样 2 次才能无失真重建，那采样率不应该是 112 G × 2 = **224 GSps** 吗？
- 疑惑二（四电平阶梯错觉）：PAM4 有 4 个电压台阶（0, 1, 2, 3），如果按标准波形从低到高依次走一遍 0 → 1 → 2 → 3 → 0...，从 0 到 3 占用了 3 个 UI，那信号频率难道不是 1 / (3 UI) 吗？
- 疑惑三（奈奎斯特带宽与 EM 仿真上限）：为什么高速信号完整性（SI）工程师总说 224G 的「奈奎斯特频率」是 56 GHz，还直接把它当成通道的「物理带宽」？在 HFSS 或 EMPro 里做 3D 全波电磁仿真提取 S 参数时，到底要不要扫到 224 GHz？

产生这些困惑的根源，并不是数学没学好，而是高频领域的「窄带载波思维」与高速数字（SI）的「超宽带基带思维」在底层语境上发生了错位。

先把核心结论放在最前面：224 Gbps 是比特率，112 GBaud 是波特率，这个信号最核心的物理带宽（奈奎斯特频率）只有 56 GHz，接收端 ADC 采样率只需 112 GSps，而 3D 电磁仿真提取到 112 GHz ~ 168 GHz 就完全足够，绝对不需要提取到 224 GHz。

下面我们把这层窗户纸彻底捅破。

## 一、破除第一层迷雾：为什么 224 Gbps 的基波只有 56 GHz？（多乘的那个「2」去哪了）

我们可以沿着信号传输的物理链路一步步往下推：

- 比特率（Bit Rate）→ 波特率（Symbol Rate）：

  224 Gbps 确实代表每秒传输 224 × 10<sup>9</sup> 个二进制 0/1 信息，平均每个 bit 耗时 4.46 ps。但现代 224G SerDes 采用 PAM4（4 电平脉冲幅度调制），用 4 个电压台阶表示 2 个 bit（格雷码 00, 01, 11, 10）。因此，物理线路上每秒只需要进行 224 ÷ 2 = **112 G** 次电压切换，即符号率 <em>R</em><sub>s</sub> = 112 GBaud，每个符号的时间宽度（称为 1 UI，Unit Interval）为 8.93 ps。

- 关键认知跃迁：1 次电平切换（1 UI）≠ 1 个完整正弦周期！

  高频工程师之所以容易算出 224 GHz，是因为潜意识里把「每秒 112 G 次动作」当成了「112 GHz 的正弦波」。

  实际上，考虑 112 GBaud 信号中频率最高的极限交替码型——电压在最高电平（3）和最低电平（0）之间每个 UI 翻转一次（3 → 0 → 3 → 0...）：

  - 停留在高电平 3 的时间是 1 UI（8.93 ps），这仅仅是半个周期；
  - 停留在低电平 0 的时间也是 1 UI（8.93 ps），这是另外半个周期；
  - 一高一低拼在一起，才构成 1 个完整的方波周期，总时长为 2 UI = 17.86 ps。

因此，这个最快跳变码型的基波正弦频率为：

<p class="eq"><em>f</em><sub>N</sub> = 1 / (2 UI) = <em>R</em><sub>s</sub> / 2 = 112 GHz / 2 = 56 GHz</p>

现在，用你最熟悉的奈奎斯特采样定理（2 倍采样）来反向验证它：既然通道里跑的最高基波正弦波只有 56 GHz，要无失真重建它，接收端 ADC 需要多高的采样率？

<p class="eq"><em>f</em><sub>s</sub> = 2 × 56 GHz = 112 GSps</p>

你看，112 GSps 恰好就是「每个 UI 采样 1 次」，逻辑严丝合缝！之前算出 224G，纯粹是因为把「半个周期（1 UI）」当成了「一个完整周期」，把 2 倍关系多乘了一次。

| 核心参数 | 数值 | 物理含义 | 对应时间尺度 |
|---|---|---|---|
| 比特率 (<em>R</em><sub>b</sub>) | 224 Gbps | 每秒传输的二进制 0/1 信息量 | 1 bit = 4.46 ps |
| 波特率 (<em>R</em><sub>s</sub>) | 112 GBaud | PAM4 下每秒电压电平切换的次数 | 1 UI = 8.93 ps |
| 奈奎斯特频率 (<em>f</em><sub>N</sub>) | 56 GHz | 最快跳变码型（3-0-3-0）的基波频率 | 1 周期 = 2 UI = 17.86 ps |
| ADC 采样率 (<em>f</em><sub>s</sub>) | 112 GSps | 对 56 GHz 基波进行 2 倍频奈奎斯特采样 | 每 UI 采样 1 次 |
| EM 提取上限 (<em>f</em><sub>max</sub>) | 112 ~ 168 GHz | 覆盖第一频谱零点（2<em>f</em><sub>N</sub>）至三次谐波（3<em>f</em><sub>N</sub>） | 捕获超过 90% 的信号能量 |

## 二、破除第二层迷雾：PAM4 有 4 个电平，按 0-1-2-3 走一遍难道不是 3 个 UI 吗？

这也是纯高频背景工程师极易踩中的第二个直觉陷阱。这里包含一个计数偏差和一个调制机理差异：

### 1. 计数偏差：0, 1, 2, 3, 0... 其实是 4 个 UI，而不是 3 个 UI

假设芯片真的按周期序列 0 → 1 → 2 → 3 → 0 → 1 → 2 → 3... 输出电压，每个电平维持 1 UI。从 0 爬到 3 确实只经历了 3 次上升沿（0→1、1→2、2→3），但不要忘了电平 3 本身也要停留 1 个 UI 之后才会掉回 0。

四根栅栏柱子循环一圈共有四个间隔，所以 0-1-2-3 阶梯波的完整周期是 4 UI = 35.71 ps，对应的基波频率只有 28 GHz（112 GHz / 4）。

### 2. 核心差异：PAM4 不是「依次爬台阶的 DAC」，而是「每个 UI 独立随机跳变」

在高频波形合成或 DDS 信号源里，如果给你 4 个量化电平，为了合成一个周期波形，确实需要按顺序走过 0 → 1 → 2 → 3 去描出波形轮廓。

但在高速数字 SerDes 里，0, 1, 2, 3 不是同一个波形上的 4 个采样点，而是 4 种独立的二进制编码。每过 8.93 ps（1 UI），发射机根据输入的 2 个随机比特，直接把驱动电压打到目标电平上，完全不需要经过中间电平过渡！

当数据流里连续出现 00 和 10 交替时，线路上的电压序列就是 0 → 3 → 0 → 3——直接从最底轨满幅度跳到最顶轨（跳过 1 和 2），下一个 UI 又立刻砸回 0。

决定物理通道带宽下限的是「木桶短板」（最快跳变码型）。如果按 0-1-2-3（28 GHz）去设计 PCB 带宽，一旦随机数据里出现 0-3-0-3（56 GHz），高频分量就会被直接滤除，接收端收到一条死线。

> 既然带宽还是 56 GHz，那 PAM4 翻倍速率的物理代价付在了哪里？
>
> 用香农公式 <em>C</em> = <em>B</em> log<sub>2</sub>(1 + SNR) 一目了然：在模拟带宽 <em>B</em> = 56 GHz 保持不变的前提下把容量翻倍，代价是垂直电压信噪比（SNR）暴跌了 3 倍（−9.54 dB）。芯片总摆幅（如 800 mV）受限于工艺无法翻倍，硬塞进 4 个台阶后，相邻电平差缩水为原来的 1/3（仅约 267 mV），这就是为什么 224G 对阻抗匹配（回波损耗 <em>S</em><sub>11</sub>）和串扰极其敏感的根本原因。

## 三、破除第三层迷雾：奈奎斯特频率凭什么直接代表「物理带宽」？

很多高频人最纳闷的是：「我们平时说奈奎斯特频率，指的是 ADC 采样率的一半（<em>f</em><sub>N</sub> = <em>f</em><sub>s</sub> / 2），防止频谱混叠；怎么到了高速数字里，突然变成物理通道的最低带宽（<em>f</em><sub>N</sub> = <em>R</em><sub>s</sub> / 2）了？」

这背后藏着通信史上最优雅的数学对偶——1928 年，哈里·奈奎斯特（Harry Nyquist）在同一篇电报传输论文中，利用傅里叶变换的时频对偶性，推导出了同一枚硬币的正反两面：

| 对比维度 | 奈奎斯特采样定理（高频 / ADC 语境） | 奈奎斯特第一准则（高速数字 / SI 语境） |
|---|---|---|
| 已知条件 | 已知连续模拟信号的最高频率 <em>B</em> | 已知每秒要发送的符号速率 <em>R</em><sub>s</sub>（波特率） |
| 物理动作放在哪个域 | 时域采样：每隔 <em>T</em><sub>s</sub> 秒乘以冲激串 ∑ δ(<em>t</em> − <em>nT</em><sub>s</sub>) | 频域限带：物理通道是一个带宽为 <em>B</em> 的低通滤波器 rect(<em>f</em> / 2<em>B</em>) |
| 另一个域发生了什么 | 频域周期延拓：宽为 2<em>B</em> 的频谱每隔 <em>f</em><sub>s</sub> = 1 / <em>T</em><sub>s</sub> 复制一次 | 时域变成 sinc(2<em>Bt</em>)：脉冲响应在 <em>t</em> = ± <em>n</em> / (2<em>B</em>) 处精准过零 |
| 防止「撞车」的临界公式 | 频谱镜像不能重叠：<em>f</em><sub>s</sub> ≥ 2<em>B</em> | 前一个脉冲的拖尾不能干扰后一个符号的采样点：<em>T</em><sub>s</sub> ≥ 1 / (2<em>B</em>) ⇒ <em>B</em> ≥ <em>R</em><sub>s</sub> / 2 |
| 撞车后的物理后果 | 频域混叠（Aliasing） | 时域混叠——码间串扰（ISI） |

为什么 <em>B</em> = <em>R</em><sub>s</sub> / 2 = 56 GHz 就是物理通道的最低带宽？

在高频电路里，矩形脉冲通过一个截止频率为 <em>B</em> 的理想低通通道后，时域冲激响应恰好是一个 sinc 函数：

<p class="eq"><em>h</em>(<em>t</em>) = 2<em>B</em> · sin(2π<em>Bt</em>) / (2π<em>Bt</em>) = 2<em>B</em> · sinc(2<em>Bt</em>)</p>

它的拖尾会在 <em>t</em> = ± 1/(2<em>B</em>), ± 2/(2<em>B</em>), ± 3/(2<em>B</em>) … 处精准穿过零点。当物理通道截止带宽恰好等于 <em>B</em> = <em>R</em><sub>s</sub> / 2 = **56 GHz** 时，第一个过零点 1/(2<em>B</em>) 刚好等于 1 UI！这意味着第 1 个脉冲在 <em>t</em> = 0 达到峰值，而它的拖尾在后续所有符号的判决时刻（1 UI, 2 UI, 3 UI…）全部严格为零，实现了无码间串扰（Zero-ISI）传输。

更精妙的是接收端的闭环重合：

- 前级「PCB 通道 + 芯片均衡器」将信号最高频率雕刻并限制在 <em>B</em> = <em>R</em><sub>s</sub> / 2 = 56 GHz（第一准则）；
- 后级接收端 ADC 面对这个最高频率为 <em>B</em> = 56 GHz 的模拟波形，根据采样定理，最低采样率为 <em>f</em><sub>s</sub> = 2<em>B</em> = 112 GSps。

两者联立，正好得出 <em>f</em><sub>s</sub> = <em>R</em><sub>s</sub>（112 GSps = 112 GBaud，即每 UI 只采 1 个点）——这就是现代 224G SerDes 芯片采用波特率采样（Baud-rate Sampling）省掉一半 ADC 功耗的理论根基。

（注：高频工程师可能会追问——实际 PCB 走线在 56 GHz 处的插损 <em>S</em><sub>21</sub> 高达 −28 dB ~ −35 dB，−3 dB 带宽连 8 GHz 都不到，怎么能叫 56 GHz 带宽？答案在于现代 SerDes 芯片内部的发射端 FFE 和接收端 CTLE/DFE 均衡器会在 56 GHz 处提供 +30 dB 的高频增益，把无源通道的滚降曲线重新「拉平」成截止频率为 56 GHz 的等效奈奎斯特通道。）

## 四、落地实战：224G 通道的 3D 电磁仿真（EM）到底要提取到多少 GHz？

既然基波是 56 GHz，那在 HFSS、EMPro 或 CST 里提取高速过孔（Via）、封装基板和连接器的 S 参数时，频率上限 <em>f</em><sub>max</sub> 该设多少？

一个 112 GBaud（UI = 8.93 ps）矩形脉冲序列的功率谱密度（PSD）服从 sinc<sup>2</sup> 分布：

<p class="eq">PSD(<em>f</em>) ∝ [sin(π<em>f</em> · UI) / (π<em>f</em> · UI)]<sup>2</sup> = [sin(π<em>f</em> / 112 GHz) / (π<em>f</em> / 112 GHz)]<sup>2</sup></p>

顺着这条频谱包络往高频看，四个关键频率节点的物理意义非常清晰：

- 56 GHz（1 × <em>f</em><sub>N</sub>，核心损耗锚点）：

  累积了约 77.4% 的信号总能量。IEEE 802.3dj 和 OIF CEI-224G 标准中，所有通道插损预算（如 C2M 通道典型限制 −28 dB）全部锚定在 56 GHz。

- 112 GHz（2 × <em>f</em><sub>N</sub>，第一频谱零点 —— 工程及格线）：

  累积了约 90.3% 的信号能量，是主瓣（Main Lobe）的终点（同时 50% 占空比方波的偶次谐波在此处为零）。这也是工程上无源通道仿真和 VNA 实测（对应 1.0 mm 同轴连接器 110 GHz 上限）的标准截止频率。

- 150 GHz ~ 168 GHz（3 × <em>f</em><sub>N</sub>，三次谐波 —— 高精度黄金标准）：

  累积了约 93.4% 的信号能量，完整保留了 56 GHz 方波的三次谐波（168 GHz），决定了脉冲边沿的上升/下降斜率。在封装、连接器和精密过孔建模时，提取到 150 ~ 168 GHz 可以防止后续在 ADS 等工具中做逆傅里叶变换（IFFT）转时域仿真时，因频域截断过于陡峭而引发吉布斯振铃（Gibbs Ringing）或非因果性（Causality）伪影。

- 为什么绝对不要提取到 224 GHz（4 × <em>f</em><sub>N</sub>）？

  从 168 GHz 到 224 GHz 仅增加了约 1.6% 的旁瓣能量，在真实物理通道中早已被介质损耗和铜箔粗糙度衰减到噪声基底以下；但 3D 全波电磁仿真在 224 GHz 下的网格数量会呈指数级暴增，且连接器/波导结构极易激发高次模（Higher-order Modes），既拖慢仿真速度又污染 S 参数精度。
